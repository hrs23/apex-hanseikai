# Get started

Apex Hanseikai is a self-hosted player for reviewing Apex Legends recordings together.

- **[Solo](solo.md)**: start here. Try it with any MP4 in five minutes.
- **[Squad of three (advanced)](squad.md)**: record everyone into one video and review it together.
